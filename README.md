# 문제로 (munjero)

시험지 HTML을 넣으면, 정답과 해설이 붙은 채점기 HTML이 나옵니다.

결과물은 파일 하나입니다. 서버도 데이터베이스도 필요 없고, 탐색기에서 더블클릭하면
바로 열립니다. 메일에 첨부해도 되고 USB에 담아도 됩니다.


## 준비 (처음 한 번만)

setup.bat 을 더블클릭하세요. 네 가지를 확인하고 없는 것은 설치합니다.

  1. Python 3.10 이상
  2. 파이썬 패키지 (pymupdf, beautifulsoup4, lxml, pillow)
  3. Codex CLI
  4. ChatGPT 로그인

4번에서 멈추면 터미널에 이렇게 치세요.

    codex.cmd login

브라우저가 열립니다. ChatGPT 계정으로 로그인하고 워크스페이스를 고른 뒤 "계속"을
누르면 됩니다. 그리고 setup.bat 을 다시 실행하세요.

개인 ChatGPT 유료 계정이면 됩니다. API 키는 쓰지 않습니다.


## 사용

시험지 HTML 을 input 폴더에 넣고 run.bat 을 더블클릭하세요.
HTML 파일을 run.bat 위로 끌어다 놓아도 됩니다.

끝나면 dist 폴더가 열립니다. 그 안의 HTML 이 채점기입니다.

세 단계가 자동으로 돕니다.

    [1/3] 매핑    시험지 HTML 에서 문항과 보기를 읽어냅니다
    [2/3] 해설    정답과 해설을 만듭니다
    [3/3] 빌드    채점기 HTML 을 만듭니다

100문항 기준으로 10분에서 15분쯤 걸립니다. 2단계가 대부분을 차지합니다.


## 꼭 알아두실 것

정답은 AI 가 만듭니다. 시험지에는 정답이 없기 때문입니다.

그래서 공식 정답표와 대조하는 작업이 반드시 필요합니다. 채점기 상단의 버튼으로
확인이 필요한 문항만 골라 볼 수 있습니다.

    확인 필요    문항을 읽어내는 과정에서 뭔가 어긋난 것
    확신 낮음    AI 가 스스로 자신 없다고 표시한 것
    정답 없음    생성에 실패한 것

주소 끝에 ?review=1 을 붙여서 열면 모든 문항의 정답과 해설이 펼쳐집니다.
인쇄하면 채점 화면 없이 문항과 해설만 나옵니다. 종이로 대조할 때 쓰세요.


## 고치기

정답이나 해설이 틀렸으면 work 폴더 안의 03_answers.json 을 고치고 다시 빌드하세요.

    python -m munjero build <시험폴더이름>

고친 항목의 source 를 "manual" 로 바꿔두면 다시 돌려도 덮어쓰지 않습니다.

dist 폴더의 HTML 을 직접 고치지는 마세요. 다시 빌드하면 사라집니다.


## 원본이 PDF 나 HWP 일 때

    python -m munjero extract "시험지.pdf"

work 폴더에 시험지 HTML 이 만들어집니다. 브라우저로 열어 확인하고 필요하면 고친 뒤
run.bat 에 넣으세요.

한글 문서가 암호화되어 있거나 배포용으로 잠겨 있으면 열리지 않습니다.
한글에서 다른 이름으로 저장을 눌러 hwpx 로 저장한 뒤 다시 시도하세요.


## 명령어

    python -m munjero doctor --smoke     환경과 로그인 점검
    python -m munjero extract <원본>      PDF/HWP 를 시험지 HTML 로
    python -m munjero run <시험지.html>    매핑부터 채점기까지 한 번에
    python -m munjero parse <시험폴더>     매핑만
    python -m munjero answer <시험폴더>    해설 생성만
    python -m munjero build <시험폴더>     채점기 빌드만

중간 파일이 단계마다 남기 때문에 원하는 단계만 다시 돌릴 수 있습니다.


## 막힐 때

로그인이 되어 있다고 나오는데 호출이 실패한다면, 토큰이 만료된 것입니다.
codex login status 는 파일만 보기 때문에 만료를 잡아내지 못합니다.
codex.cmd login 으로 다시 로그인하세요.

PowerShell 에서 codex 를 쳤을 때 보안 오류가 난다면 codex.cmd 를 쓰세요.
윈도우 실행 정책이 npm 이 만든 스크립트를 막는 것이며, .cmd 는 그 대상이 아닙니다.

사내망에서 글꼴이 안 보이면 --no-cdn 을 붙이세요. 맑은 고딕으로 나옵니다.
