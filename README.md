# 문제로 (munjero)

시험지 HTML을 넣으면, 정답과 해설이 붙은 채점기 HTML이 나옵니다.

결과는 파일 하나입니다. 서버도 데이터베이스도 필요 없고, 더블클릭하면 열립니다.
메일에 첨부해도 되고 USB에 담아도 됩니다.


## 준비 (처음 한 번만)

setup.bat 을 더블클릭하세요. 네 가지를 확인하고 없는 것은 설치합니다.

    1. Python 3.10 이상
    2. 파이썬 패키지
    3. Codex CLI
    4. ChatGPT 로그인

4번에서 멈추면 터미널에 이렇게 치세요.

    codex.cmd login

브라우저가 열립니다. ChatGPT 계정으로 로그인하고 워크스페이스를 고른 뒤 "계속"을
누르면 됩니다. 그리고 setup.bat 을 다시 실행하세요.

본인 ChatGPT 유료 계정이면 됩니다. API 키는 쓰지 않습니다.


## 쓰는 법

run.bat 을 더블클릭하면 브라우저가 열립니다.

    http://127.0.0.1:7085/

시험지를 화면에 끌어다 놓으면 시작합니다.


## 네 단계와 두 번의 확정

    1. 문제 읽어내기      시험지에서 문항과 보기를 뽑습니다
       ── 입력 확정 ──   제자리에 있는지 보고 고친 뒤 확정합니다
    2. 정답과 해설        AI가 초안을 만듭니다
       ── 해설 확정 ──   읽어보고 고친 뒤 확정합니다
    3. 채점기 내보내기

확정하기 전에는 다음 단계가 열리지 않습니다.

자리가 틀린 채로 정답을 만들면 그 시간이 그대로 버려지기 때문입니다.
100문항에 10~15분쯤 걸립니다.


## 화면

    왼쪽    단계 · 최근 시험지 · 저장 폴더
    가운데  시작 / 목차 / 문항 / 정답·해설 / 내보내기
    오른쪽  문항 구성 · 실행현황 (탭을 눌러 엽니다)

현황판을 누르면 격자가 뜹니다. 행은 발문·지문·표·그림·보기·정답·해설,
열은 문항 번호입니다. 빈 칸을 누르면 그 문항을 고치는 화면으로 갑니다.

문항 화면은 한 번에 하나씩 봅니다. 지문을 나눠 쓰는 묶음 문제는
지문 하나에 문항 여러 개를 한 화면에 놓습니다.
좌우 방향키로 넘기고 Enter 로 확인합니다.


## 고칠 수 있는 것

문항 편집 화면에서 이런 것들을 고칩니다.

    문항 번호, 발문, 지문, 보기
    표 — 칸을 눌러 고칩니다. 좌변과 우변이 통째로 바뀌었으면 버튼 하나로 바꿉니다
    코드 블록
    그림 — 캡처해서 붙여넣은 것도 그대로 살아옵니다

한 문항이 둘로 쪼개져 들어왔으면 "앞 문항에 붙이기"로 합칩니다.
끊어진 지문은 지문 칸에서 직접 이어 쓰면 됩니다.

해설 화면에서는 정답을 눌러 바꾸고, 해설을 고치고, 도표가 마음에 안 들면 뺍니다.
사람이 고친 것은 다시 만들어도 덮어쓰지 않습니다.


## 넣을 수 있는 파일

    HTML          권합니다. 가장 잘 읽힙니다
    워드 docx     잘 됩니다
    한글 hwpx     잘 됩니다. 표 병합과 그림이 그대로 옵니다
    한글 hwp      됩니다. 예전 형식이라 hwpx 를 권합니다
    PDF           조판을 탑니다
    zip           HTML 과 그림 폴더를 함께 묶어 넣을 때

워드·한글·구글 문서에서 웹 페이지로 저장한 것이면 됩니다. 가급적 HTML 로 넣어 주세요.
한글은 [다른 이름으로 저장 > 한글 표준 문서(*.hwpx)] 로 저장해 주세요.

PDF는 글자에 좌표만 있고 구조가 없어서 조판을 많이 탑니다. 어긋나면 HTML로 저장해 넣으세요.

그림이 있는 HTML은 [웹 페이지 - 한 개 파일]로 저장하세요. 폴더로 나뉘면 그림이 빠집니다.
이미 나뉘었다면 폴더째 zip으로 묶어 넣어도 됩니다.

복잡한 표나 그림은 캡처해서 이미지로 붙여넣어도 됩니다. 그대로 나옵니다.


## 꼭 알아두실 것

정답은 AI가 만듭니다. 시험지에는 정답이 없기 때문입니다.

그래서 공식 정답표와 대조하는 작업이 반드시 필요합니다. 채점기 상단의 버튼으로
확인이 필요한 문항만 골라 볼 수 있습니다.

    확인 필요    문항을 읽어내는 과정에서 뭔가 어긋난 것
    확신 낮음    AI가 스스로 자신 없다고 표시한 것
    정답 없음    만들지 못한 것

주소 끝에 ?review=1 을 붙여서 열면 모든 문항의 정답과 해설이 펼쳐집니다.
인쇄하면 채점 화면 없이 문항과 해설만 나옵니다. 종이로 대조할 때 쓰세요.


## 폴더

시험마다 폴더가 하나씩 생깁니다. 기본 위치는 munjero-output 이고,
화면 왼쪽 아래에서 바꿀 수 있습니다.

    00_source     넣은 원본 파일
    01_paper      읽어낸 시험지 HTML
    02_items      문항 데이터
    03_answers    정답과 해설
    04_grader     채점기
    04_grader/이전  지난 채점기들

저자가 나중에 문제를 고쳐도 됩니다. 바뀐 문항만 "문제가 바뀜"으로 표시되고
나머지 검수한 해설은 그대로 남습니다.


## 명령어로 쓰기

화면 없이도 됩니다.

    python -m munjero doctor --smoke   환경과 로그인 점검
    python -m munjero map <파일>       읽어내기 (확인 지점에서 멈춤)
    python -m munjero answer <파일>    정답과 해설
    python -m munjero build <파일>     채점기
    python -m munjero list             만든 시험 목록


## 막힐 때

로그인이 되어 있다고 나오는데 호출이 실패한다면, 토큰이 만료된 것입니다.
codex login status 는 파일만 보기 때문에 만료를 잡아내지 못합니다.
codex.cmd login 으로 다시 로그인하세요.

PowerShell 에서 codex 를 쳤을 때 보안 오류가 난다면 codex.cmd 를 쓰세요.
윈도우 실행 정책이 npm 이 만든 스크립트를 막는 것이며, .cmd 는 그 대상이 아닙니다.

포트가 이미 쓰이고 있으면 run.bat 이 알아서 정리하고 시작합니다.
다른 프로그램이 쓰고 있으면 건드리지 않고 다음 포트로 비켜갑니다.

사내망에서 글꼴이 안 보여도 글자는 맑은 고딕으로 나옵니다.


## 구조

    server.py       웹 서버
    routes/         화면이 부르는 API
    static/         화면
    munjero/        코드
      ingest/       원본 → 시험지 HTML
      parse/        시험지 HTML → 문항
      answer/       정답과 해설 (Codex CLI)
      build/        채점기
      templates/    채점기 틀
