# 문제로 (munjero)

시험지 HTML을 넣으면, 정답과 해설이 붙은 채점기 HTML이 나옵니다.

결과물은 파일 하나입니다. 서버도 데이터베이스도 필요 없고, 탐색기에서 더블클릭하면
바로 열립니다. 메일에 첨부해도 되고 USB에 담아도 됩니다.


## 준비 (처음 한 번만)

setup.bat 을 더블클릭하세요. 네 가지를 확인하고 없는 것은 설치합니다.

  1. Python 3.10 이상
  2. 파이썬 패키지 (pymupdf, beautifulsoup4, lxml, pillow)
  3. Codex CLI
  4. ChatGPT 로그인

4번에서 멈추면 터미널에 이렇게 치세요.

    codex.cmd login

브라우저가 열립니다. ChatGPT 계정으로 로그인하고 워크스페이스를 고른 뒤 "계속"을
누르면 됩니다. 그리고 setup.bat 을 다시 실행하세요.

개인 ChatGPT 유료 계정이면 됩니다. API 키는 쓰지 않습니다.


## 사용

시험지 파일을 run.bat 위로 끌어다 놓거나, input 폴더에 넣고 run.bat 을 더블클릭하세요.
HTML, PDF, 한글 파일 모두 됩니다.

세 단계로 진행되고, 중간에 한 번 멈춰서 물어봅니다.

    1 단계   문제 읽어내기     시험지에서 문항과 보기를 뽑습니다
    확인     여기서 멈춥니다   제자리에 있는지 눈으로 봅니다
    2 단계   정답과 해설       AI 가 만듭니다 (100문항에 10~15분)
    3 단계   채점기 만들기     더블클릭으로 열리는 파일이 나옵니다


## 중간에 멈추는 이유

1단계가 끝나면 읽어낸 시험지가 브라우저에 열립니다.
문항 번호, 보기 4개, 지문이 제자리에 있는지 봐주세요.
빨간 줄이 있으면 그 자리는 읽어내지 못한 곳입니다.

자리가 틀린 채로 넘어가면 그 상태로 정답과 해설을 만듭니다.
10~15분이 그대로 버려집니다. 그래서 넘어가기 전에 물어봅니다.

이상하면 창을 닫고, 열린 HTML 파일을 직접 고친 다음 run.bat 을 다시 실행하세요.
읽어낸 내용은 그대로 남아 있습니다.


## 꼭 알아두실 것

정답은 AI 가 만듭니다. 시험지에는 정답이 없기 때문입니다.

그래서 공식 정답표와 대조하는 작업이 반드시 필요합니다. 채점기 상단의 버튼으로
확인이 필요한 문항만 골라 볼 수 있습니다.

    확인 필요    문항을 읽어내는 과정에서 뭔가 어긋난 것
    확신 낮음    AI 가 스스로 자신 없다고 표시한 것
    정답 없음    생성에 실패한 것

주소 끝에 ?review=1 을 붙여서 열면 모든 문항의 정답과 해설이 펼쳐집니다.
인쇄하면 채점 화면 없이 문항과 해설만 나옵니다. 종이로 대조할 때 쓰세요.


## 해설에 들어가는 표와 그림

계산이나 대조가 필요한 해설에는 표가 들어갑니다. 분개는 차변/대변 표로, 원가는
단계별 계산 표로 나옵니다.

그림이 있어야 설명이 짧아지는 문항에는 도표가 들어갑니다. 위험이 넘어가는 지점,
당사자 사이의 흐름, T계정, 원가 흐름 같은 것들입니다. 단순 암기나 어법 문항에는
넣지 않습니다. 억지로 그린 도형은 오히려 해설을 믿기 어렵게 만들기 때문입니다.

도표는 AI가 만들지만 화면에 넣기 전에 걸러집니다. 도형과 글자만 통과시키고
스크립트나 외부 참조는 버립니다. 색은 채점기 팔레트만 쓰게 되어 있어서 화면과
따로 놀지 않습니다.

도표가 마음에 들지 않으면 03_answers.json 에서 diagram_svg 를 null 로 바꾸고
다시 빌드하면 사라집니다.


## 고치기

정답이나 해설이 틀렸으면 work 폴더 안의 03_answers.json 을 고치고 다시 빌드하세요.

    python -m munjero build <시험폴더이름>

고친 항목의 source 를 "manual" 로 바꿔두면 다시 돌려도 덮어쓰지 않습니다.

dist 폴더의 HTML 을 직접 고치지는 마세요. 다시 빌드하면 사라집니다.


## 원본이 PDF 나 HWP 일 때

그대로 넣으면 됩니다. run.bat 이 알아서 시험지 HTML 로 바꾼 뒤 보여줍니다.

한글 문서가 암호화되어 있거나 배포용으로 잠겨 있으면 열리지 않습니다.
한글에서 다른 이름으로 저장을 눌러 hwpx 로 저장한 뒤 다시 시도하세요.

시험지 안의 로고, 버튼, 빈 서식 용지 같은 그림은 자동으로 빼냅니다.
무엇을 왜 뺐는지 화면에 적어줍니다. 사업자등록증이나 세금계산서의 내용은
그림이 아니라 표로 들어 있어서 그대로 살아옵니다.


## 명령어

    python -m munjero doctor --smoke   환경과 로그인 점검
    python -m munjero map <파일>       읽어내기 + 문항 뽑기 (확인 지점에서 멈춤)
    python -m munjero answer <파일>    정답과 해설
    python -m munjero build <파일>     채점기
    python -m munjero list             만들어 둔 시험 목록
    python -m munjero run <파일>       확인 없이 끝까지 (급할 때만)

파일 경로 대신 시험 이름을 써도 됩니다.

중간 파일이 단계마다 남기 때문에 원하는 단계만 다시 돌릴 수 있습니다.


## 폴더

시험마다 폴더가 하나씩 생깁니다. 위치는 이 폴더 바깥의 munjero-output 입니다.

    00_source     넣은 원본 파일
    01_paper      읽어낸 시험지 HTML     <- 문항 자리를 고칠 곳
    02_items      문항 데이터
    03_answers    정답과 해설            <- 해설을 고칠 곳
    04_grader     채점기                 <- 결과물

단계가 파일로 남아 있어서, 고친 다음 그 뒤 단계만 다시 돌릴 수 있습니다.

만들어 둔 시험 목록은 이렇게 봅니다.

    python -m munjero list

출력 위치를 바꾸려면 MUNJERO_OUT 환경변수나 --out-root 를 씁니다.

setup.bat 과 run.bat 은 이 폴더와 바깥 폴더 양쪽에 있습니다. 어느 쪽을 눌러도 됩니다.


## 막힐 때

로그인이 되어 있다고 나오는데 호출이 실패한다면, 토큰이 만료된 것입니다.
codex login status 는 파일만 보기 때문에 만료를 잡아내지 못합니다.
codex.cmd login 으로 다시 로그인하세요.

PowerShell 에서 codex 를 쳤을 때 보안 오류가 난다면 codex.cmd 를 쓰세요.
윈도우 실행 정책이 npm 이 만든 스크립트를 막는 것이며, .cmd 는 그 대상이 아닙니다.

사내망에서 글꼴이 안 보이면 --no-cdn 을 붙이세요. 맑은 고딕으로 나옵니다.

표가 좁아 보이면 가로로 밀어서 볼 수 있습니다. 열이 많은 서식(사업자등록증,
세금계산서)은 글자를 줄이고 가로 스크롤로 처리합니다.

채점기 파일이 너무 크면 --split-data 를 붙이세요. 그림이 많은 시험에서
파일이 몇 MB가 될 수 있습니다.
