# 디자인 토큰과 정답색 충돌

색은 `templates/grader.html` 의 `:root` 한 곳에만 있다. 규칙에는 하드코딩하지 않는다.

## 왜 정답 초록을 옮겼는가

브랜드가 teal이면 흔히 쓰는 정답 초록 `#0f9d58` 과 사실상 구분되지 않는다.
OKLab ΔE로 실측한 값이다.

```
#0d9488(brand-600) ↔ #0f9d58   ΔE  8.2 · 2형색각 ΔE  5.1   구분 불가
#0d9488            ↔ #4a9c2d   ΔE 12.1 · 2형색각 ΔE 11.4   채택
#4a9c2d            ↔ #e23b4e   ΔE 31.8 · 2형색각 ΔE 28.7   충분
```

`#4a9c2d` 가 너무 라임으로 보인다는 피드백이 나오면 `#3d9a3f`(ΔE 10.4 / 9.1)로 내린다.

## 대비

```
#0f3d3a  brand-ink   12.01:1   본문·제목
#0b7c72  brand-700    5.07:1   CTA 채움 — 흰 글자 올려도 AA 통과
#0d9488  brand-600    3.74:1   테두리·배지만. 본문 텍스트 금지
#14b8a6  brand-500    2.49:1   도넛 스트로크 전용. 텍스트 금지
#4a9c2d  correct      3.45:1   채움(3:1 기준 통과)
#2f6b13  correct-text 6.49:1   정답 텍스트
#c22638  wrong-text   5.79:1   오답 텍스트
```

**CTA 채움은 `--brand-600` 이 아니라 `--brand-700` 이다.** `#0d9488` 에 흰 글자는 3.74:1로
본문 대비 기준에 못 미친다.

## 충돌 회피 4원칙

**1. 역할 분리.** teal은 크롬 전용(헤더·탭·버튼·문항번호·게이지·포커스링).
초록/빨강은 채점 결과 전용. `--brand-*` 가 `.q-choice*` 규칙에 나타나면 안 된다.

**2. hue 이동.** 위 표대로.

**3. 색 외 채널 중복 — 선택이 아니라 필수.**
tint 배경끼리는 **어떤 hue로도 ΔE 2~4밖에 안 벌어진다**(실측: `#f1f8e8` vs `#eefbf8` = 2.0).
배경색만으로는 절대 구분되지 않는다. 그래서 항상 함께 쓴다.

- 정답: 2px `--correct-bd` 테두리 + `정답` 칩
- 오답: 2px `--wrong-bd` 테두리 + `내가 고른 답` 칩
- 인쇄본에서는 정답 마커 뒤에 `✓` 를 붙인다

**4. 선택 상태에 tint를 쓰지 않는다.**
선택을 `background: --brand-50` 으로 두면, 채점 후 `--correct-soft` 로 바뀌어도 ΔE 2.0이라
**사용자 눈에는 아무것도 안 바뀐 것처럼 보인다.**
선택은 테두리 2px + 마커 반전으로만 표시한다. 그래야 채점 후 tint 등장이 새 정보로 읽힌다.

## 디자인팀에 넘길 때

- 클래스명은 BEM-lite다. `.q-card` `.q-stem` `.q-choice--selected` `.q-explain`
- 인라인 `style=` 은 한 곳도 없다
- 각 문항 카드에 `data-id` `data-number` 가 있어 요소를 지목할 수 있다
- 색을 바꾸려면 `:root` 의 토큰만 고치면 된다
